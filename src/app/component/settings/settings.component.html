Servers & video

Pick a video engine and paste Zoom or Jitsi credentials here. Signaling still comes from src/app/config/call.config.ts.

Video engine

Jitsi and Zoom Video SDK each create a unique room per pair. WebRTC is peer-to-peer through LearnLink API.

Jitsi Meet SDK

Leave keys empty to use the public meet.ffmuc.net embed. For 8x8 JaaS, set domain 8x8.vc and paste the App ID, Key ID, and PKCS#8 private key.

Zoom Video SDK

Create a Video SDK app at marketplace.zoom.us (not Meeting SDK). Copy the SDK Key and SDK Secret. Each 1:1 call uses session learnlink-{smallerId}-{largerId} — no Zoom meeting number. Prefer putting the secret on LearnLink API so the browser does not store it.

LearnLink API

Visual Studio IIS Express serves two URLs for the same app: Swagger at https://localhost:44388 and HTTP at http://localhost:21262. Detect prefers HTTPS first. Zoom Video SDK tokens are POST /api/zoom/token.
